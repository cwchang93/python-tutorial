# 通用教師指南

## 每堂固定節奏（180 分鐘）

| 時間 | 活動 |
|---|---|
| 0–15 | 回顧、情境問題、今日成果預覽 |
| 15–45 | 核心概念與短示範 |
| 45–75 | 教師 Live Coding，學生同步操作 |
| 75–85 | 休息與環境排錯 |
| 85–120 | Core 引導練習 |
| 120–150 | Practice 獨立練習 |
| 150–170 | 解答、常見錯誤、Challenge |
| 170–180 | Exit Ticket、作業與下堂預告 |

## 備課只做四件事

1. 執行本堂 learning 與 solutions notebook。
2. 閱讀本堂 README 的時間腳本與常見卡點。
3. 確認 `data/` 可用，並保留 Colab 備案。
4. 決定當班只做到 Core，或加做 Practice／Challenge。

## 通用講法

- 先展示輸出，再拆解程式。
- 每個新語法都回答：「資料分析何時會用到？」
- 投影片講概念，Notebook 放完整程式碼。
- 不要求背語法；要求學生能閱讀、修改、執行與解釋。
- 錯誤訊息先看最後一行，再找出錯的 cell。

## 課後 5 分鐘紀錄

在本堂 README 的「課後紀錄」填寫：

- 實際進度
- 最常見問題
- 太難或太簡單的題目
- 下次應刪除或補充的內容
- 實際時間差

## 發布原則

- 學生只取得 learning、exercises、homework 與 data。
- solutions 與教師備課內容留在私人環境。
- 對外教材固定版本，不在上課中直接重寫正式版。
