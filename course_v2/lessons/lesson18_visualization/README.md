# Lesson 18｜Matplotlib 與圖表選擇

這一課把 Lesson 17 的統計結果轉成圖表。學生先判斷問題是「比較、趨勢、占比或關係」，再選擇適合的圖，最後練習寫出不過度推論的結論。

## 學習目標

- 認識 `matplotlib.pyplot` 與常用縮寫 `plt`
- 使用長條圖比較類別並呈現排名
- 使用折線圖呈現依時間排列的趨勢
- 在分類少且構成整體時使用圓餅圖
- 使用散佈圖觀察兩個數值欄位的關係
- 正確設定標題、座標軸、圖例、格線、顏色與畫布大小
- 避免時間未排序、長條圖截斷零點及分類過多的圓餅圖
- 使用 Pandas `.plot()` 快速建圖，再用 Matplotlib 完成標示
- 使用 `savefig()` 儲存圖表
- 分辨「圖上看到的現象」與「資料尚未證明的原因」

## 生活化比喻

- 長條圖像頒獎台，適合比較誰高誰低。
- 折線圖像健康紀錄，重點是時間中的變化。
- 圓餅圖像分披薩，只適合少數分類共同組成百分之百。
- 散佈圖像在操場上看學生分布，用每一個點觀察兩個數字是否有關係。

## 本課邊界

本課不教複雜美化、互動圖表或 Seaborn。學生只要能選對圖、標示清楚、讀出現象並避免過度推論，就足以進入 Lesson 19 專案工作坊。
