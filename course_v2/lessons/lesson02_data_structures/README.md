# Lesson 02-2｜List、Tuple、Dict、Set

## 學習成果

- 能說明變數與資料結構的差別。
- 能建立、讀取、修改與增刪 `list`。
- 能用 `dict` 表示一筆具有欄位名稱的資料。
- 能依「固定資料」與「去除重複」需求選擇 `tuple` 或 `set`。
- 能根據真實情境選擇合適的資料結構。

## 教學取捨

- 核心：`list`、`dict`。
- 認識：`tuple`、`set`，只要求能判斷使用情境。
- 暫不深入：巢狀資料結構、集合運算、comprehension。

## 常見卡點

- Index 從 `0` 開始，`-1` 代表最後一筆。
- `append()` 會修改原本的 List，不需要再指定回去。
- Dict 用 Key 讀取，不是用位置。
- `{}` 是空 Dict；空 Set 必須寫成 `set()`。
