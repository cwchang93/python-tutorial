# Lesson 05｜Dict 深入與 Set 入門

## 學習成果

- 能用 Key-Value 建立與讀取 `dict`。
- 能新增、修改、刪除欄位並使用 `.get()` 安全查詢。
- 能用 Dict 描述學生、商品、會員或訂單。
- 能使用 `set` 去除重複資料。
- 能使用 `keys()`、`values()`、`items()`、`update()` 與 `pop()` 整理欄位資料。
- 能使用 Set 的交集、聯集與差集比較名單。
- 能初步整合 List、Dict、Set 與條件判斷。

## 分級原則

- ⭐ 必做 6 題：Dict 基本操作與 Set 去重。
- ⭐⭐ 應用 6 題：會員、商品、多位學生與集合運算。
- ⭐⭐⭐ 挑戰 3 題：商品小卡、報名整理器、學習儀表板。
- Set 只要求理解唯一值與基礎集合運算。

## 常見卡點

- Dict 用 Key，不是用位置查詢。
- 找不到 Key 時優先考慮 `.get()`。
- `in some_dict` 檢查的是 Key。
- `{}` 是空 Dict；空 Set 必須使用 `set()`。
- Set 沒有固定順序，也不能使用 Index。
