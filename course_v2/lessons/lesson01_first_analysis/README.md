# Lesson 01｜Python 初體驗與 Notebook

## 學習成果

- 能操作 Jupyter Notebook 的 Markdown 與 Code cell。
- 能使用 `print()` 顯示文字與數字。
- 能修改簡單變數並重新執行程式。
- 能完成自我介紹與消費金額小程式。

## 必做與彈性內容

- Core：執行 cell、使用 print、修改文字與數字。
- Practice：用變數計算飲料總價。
- Challenge：製作可展示的個人數位名片。

## 教學節奏建議

- 每個範例先請學生預測，再執行，最後修改一個值。
- Lesson 01 安裝若花費較久，可只完成 learning 1–4 與練習 Core。
- 小作品保留為彈性內容；環境順利的班級可在課堂完成。

## 常見卡點

- cell 沒有輸出：確認是 Code cell 並按 Shift+Enter。
- 引號左右不一致：重新輸入半形 `'` 或 `"`。
- 把文字寫在引號外：示範 Python 如何區分程式與文字。
- 變數拼錯：讓學生比較左右兩個名稱是否完全相同。
