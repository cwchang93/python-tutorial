# Lesson 02｜變數、型別與訂單計算

## 學習成果

- 能使用變數保存資料。
- 能用生活情境選擇 `int`、`float`、`str`、`bool`。
- 能理解比較運算會產生 `bool`。
- 能區分「看起來像數字」與「需要拿來計算」的資料。
- 能用 `int()`、`float()`、`str()` 做型別轉換。
- 能完成單價、數量、折扣與營收計算。

## 必做與彈性內容

- Core：變數、四種基本型態、比較與型別轉換。
- Practice：生活資料分類、字串操作與折扣。
- Challenge：完成活動報名確認單。

## 教學節奏建議

- 每個型態範例都搭配一個預測題，避免只背名稱。
- 問學生「這筆資料要不要計算？」來區分 `str` 與數值型態。
- `bool` 先用付款、登入、門票等生活開關，再銜接比較運算。
- `input()` 先示範文字，再示範數字轉型與常見錯誤。
- 班級進度較快時加入分帳計算器；較慢時留作課後練習。

## 常見卡點

- `input()` 結果永遠是字串，要先轉型才能做數值運算。
- `=` 是指定，`==` 才是比較；本堂先認識，不深入條件判斷。
- 金額顯示用 `:.2f`，先當作格式模板，不要求背誦。
- 變數名稱不要使用空白、中文標點或以數字開頭。
