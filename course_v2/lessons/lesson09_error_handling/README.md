# Lesson 09｜錯誤處理

## 學習成果

- 能辨識本課程的核心概念並用生活化案例說明。
- 能完成 25 個 learning 示範、25 題 exercises 與對應 solutions。
- 能把語法放進小型資料處理流程。

## 教材檔案

- `lesson09_learning.ipynb`：25 個完整示範例題。
- `lesson09_exercises.ipynb`：25 題分級課堂練習。
- `lesson09_solutions.ipynb`：與課堂練習逐題對應的 25 題解答。
- `lesson09_homework.ipynb`：課後整合任務。

## 教學提醒

先讀懂錯誤，再用 try、except、else、finally 保護程式。
