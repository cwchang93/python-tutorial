# Lesson 08｜函式 Function

## 學習成果

- 能說明函式如何減少重複程式碼。
- 能使用 `def` 定義函式並正確呼叫。
- 能使用一個或多個參數接收資料。
- 能使用 `return` 回傳結果，並區分 `print` 與 `return`。
- 能理解區域變數只在函式內有效。
- 能使用預設參數設計容易使用的函式。
- 能把驗證、計算與報表邏輯拆成可重複使用的小函式。

## 常見卡點

- 定義函式後仍要加上 `()` 才會執行。
- 參數是函式收到的資料，呼叫時要依順序提供。
- `print()` 只顯示結果；`return` 才能把結果交給下一段程式。
- `return` 執行後，函式會立刻結束。
- 函式內建立的區域變數，不能直接在函式外使用。
