# Lesson 04｜List 深入與 Tuple 入門

## 學習成果

- 能建立、讀取、修改與增刪 `list`。
- 能使用 Index、負數 Index 與切片取得資料。
- 能使用 `in`、`len()`、`sum()`、`min()`、`max()` 處理清單。
- 能說明 `list` 與 `tuple` 的主要差異。
- 能用 List 完成候位、購物車或任務板。

## 常見卡點

- Index 從 `0` 開始，`-1` 是最後一筆。
- 切片的結束位置不包含在結果中。
- `append()` 修改原 List，不用再指定回去。
- `remove()` 依內容；`pop()` 依位置。
- Tuple 建立後不能修改。
