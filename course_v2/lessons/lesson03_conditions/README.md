# Lesson 03｜if、elif、else 條件判斷

## 學習成果

- 能說明比較運算如何產生 `True` 或 `False`。
- 能使用 `if` 處理條件成立的情況。
- 能使用 `if / else` 處理兩種互斥結果。
- 能使用 `if / elif / else` 處理多種情況。
- 能使用 `and`、`or`、`not` 組合生活規則。
- 能檢查冒號、縮排、條件順序、邊界值及輸入型態。

## 運算子銜接

Lesson 03 開始先用 8 題運算暖身，順序是「先算出結果 → 比較 → 得到 bool → 進入 if」。
Lesson 02 投影片最後新增運算子章節，讓學生課前先看過 `+ - * / // % **` 與 `== != > < >= <=`。

題型設計參考 [Snakify：Conditions — if, then, else](https://snakify.org/en/lessons/if_then_else_conditions/)，並改寫成繁中生活情境與分級版本。

## 教學取捨

- 核心：`if`、`elif`、`else`、比較運算、縮排。
- 練習：`and`、`or`、`not` 與 `input()` 型態轉換。
- 認識：巢狀 `if`，只示範一層。
- 暫不深入：三元運算、`match`、複雜巢狀條件。

## 常見卡點

- `=` 是指定；`==` 才是比較。
- 條件後面要有冒號 `:`。
- 分支內容統一縮排 4 個空格。
- `elif` 的順序會影響結果，通常先放較嚴格條件。
- `input()` 得到的是 `str`，數值比較前要先轉型。
- `>=` 與 `>` 的差別會影響邊界值。
