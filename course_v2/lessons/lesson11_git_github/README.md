# Lesson 11｜Git 與 GitHub 入門

## 學習成果

- 能用自己的話說明本課的核心流程。
- 能完成 25 個 learning 示範、25 題 exercises 與對應 solutions。
- 能把前面學過的語法放進可保存、可分享的小型作品。

## 教材檔案

- `lesson11_learning.ipynb`：25 個逐步示範。
- `lesson11_exercises.ipynb`：25 題課堂練習。
- `lesson11_solutions.ipynb`：逐題完整解答。
- `lesson11_homework.ipynb`：課後整合任務。

## 教學提醒

先建立本機版本觀念，再帶到 GitHub。課堂只教 init、status、add、commit、log、remote、push、pull、clone，不加入分支與多人協作。
