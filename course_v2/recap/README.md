# 課前複習

每次進入新單元前，先用 10–20 分鐘完成一輪短複習。

- `lessonXX_YY_review.ipynb`：學生題目
- `lessonXX_YY_review_solutions.ipynb`：講師解答

建議流程：先個人作答 8 分鐘，再兩人互相檢查，最後講師快速檢討。

`lesson11_12_review.ipynb` 另外包含一條完整但安全的 Git 實作流程：在獨立資料夾建立專案、初始化 Git、修改 Python 程式並建立 Commit。GitHub 建立 Repository、設定 Remote 與 Push 只顯示操作步驟，不會由 Notebook 自動連線或推送。
