# Python 資料分析課程綱要

## 課程定位

- 對象：沒有程式設計經驗的初學者
- 主軸：Python 基礎 → 資料處理 → Pandas 資料分析 → 完成分析作品
- 教學節奏：延續 Lesson 03、04 的速度與難度
- 每堂課原則：講解一個觀念，立即練習，再一起檢討
- 建議比例：30～40% 講解、60～70% 實作與檢討
- 題目以生活化情境為主，必要時補充簡單 TQC 題型
- 答案需標示清楚，例如「最高分」「最低分」「總數」，避免只輸出一串數字

## Git 與 GitHub 的安排

不在環境架設時加入 Git，避免 Lesson 01 同時處理太多新工具。

Lesson 11 先教最必要的操作：

- Repository
- Commit
- Push
- Pull
- Clone

暫時不教複雜分支、多人協作與 GitHub Actions。等學生有實際程式碼後，再把 Git 當成保存與分享作品的工具。

## OOP 的安排

本課程不把物件導向列為核心單元。資料分析初學者不需要先學完整的 Class、Object、`self`、繼承等概念。

只在 Pandas 開始時用一頁簡短介紹：

> DataFrame 與 Series 也是 Python 物件，我們可以呼叫它們的方法。

不安排獨立 OOP 實作課，避免偏離資料分析主線。

## Recursive（遞迴）的安排

本課程不教 Recursive。

遞迴很適合樹狀結構、檔案系統與演算法課程，但對本課程的 CSV、Pandas、資料清理與視覺化沒有直接必要性。它會引入函式呼叫堆疊、終止條件與深度等額外抽象，對目前新手程度不划算。

如果未來開設進階 Python／演算法課，再獨立安排 Recursive，並搭配階乘、樹狀資料或資料夾搜尋案例。

## 資料來源與資料庫決策

核心課程不架設 MySQL、PostgreSQL 或其他資料庫。資料庫會增加安裝、帳號、權限、SQL 與連線設定，不符合本期新手課程的主線。

主要資料來源：

1. 專案內 CSV：確保每位同學資料一致、不依賴網路
2. Google Sheets 匯出 CSV：作為生活化資料來源
3. 選配展示：Google Apps Script 提供簡單 JSON API

Google Sheets／Apps Script 不列為必裝環節。未來若開進階班，再教 SQLite、SQL、Google Sheets API 與資料庫連線。

## Lesson 18 後的專案節奏

Lesson 18 後不再大量增加新語法，改以作品完成為主：

- 20% 講解
- 60% 學生實作
- 20% 老師示範與檢討

學生完成一份包含資料清理、統計、圖表與結論的分析作品，並用 GitHub 保存與分享。

## 實作時如何找資料

學生不需要一開始就自己在網路上漫無目的搜尋。課堂先提供一份「資料來源清單」與幾個示範資料集，再讓學生依興趣挑選。

### 優先推薦的資料來源

1. **臺灣政府資料開放平臺**：<https://data.gov.tw/>
   - 適合找交通、人口、天氣、觀光、教育、公共安全等臺灣生活資料。
   - 搜尋時加上 `CSV`、`JSON` 或「開放資料」等關鍵字。
2. **Kaggle Datasets**：<https://www.kaggle.com/datasets>
   - 適合找電商、電影、餐廳、運動、銷售與生活調查資料。
   - 初學者先挑 CSV、小於約 50 MB、有欄位說明的資料集。
3. **UCI Machine Learning Repository**：<https://archive.ics.uci.edu/>
   - 適合使用整理過的經典資料集，例如 Iris、Wine、學生表現等。
4. **Our World in Data**：<https://ourworldindata.org/>
   - 適合人口、健康、能源、氣候與國際比較；許多圖表可下載 CSV。
5. **課程提供的資料集**
   - 課程先準備幾份已確認欄位、授權與格式的 CSV，避免學生花整堂課處理下載或清理問題。

### 找資料的步驟

1. 先寫一個想回答的問題，例如：「哪一個月份的銷售額最高？」
2. 再找可能包含答案的欄位，例如日期、商品、數量、金額。
3. 下載 CSV 後先用記事本或 VS Code 查看欄位，不要直接開始分析。
4. 確認資料筆數、欄位名稱、缺失值、重複值與日期格式。
5. 在 `data/` 資料夾保存原始資料，清理後的檔案另存，不覆蓋原始檔。
6. 在作品 README 記錄資料來源、下載日期、授權與分析問題。

### 初學者挑選資料集的檢查表

- 至少有 5 個欄位，且能提出 2～3 個分析問題
- 有數字欄位，也有分類或日期欄位
- 檔案大小適中，能在一般學生電腦上開啟
- 欄位名稱與內容看得懂
- 有清楚的資料來源與使用授權
- 不包含個人敏感資料

### 不建議一開始使用

- 只有圖片、音訊或文字檔，沒有表格欄位的資料
- 超過數百 MB、需要資料庫才能處理的資料
- 沒有欄位說明或來源不明的資料
- 需要爬蟲、登入或付費 API 才能取得的資料

Lesson 19 可以先讓每位同學從 3～5 份教師準備好的候選資料中選一份；完成一次分析流程後，再鼓勵有餘力的同學自行找 Kaggle 或政府開放資料。
